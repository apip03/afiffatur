Project Overview

An industrial-grade automated sorting conveyor testbed implementing closed-loop PID speed control engineered as part of the Control System Design (Desain Sistem Kontrol) course at ITS. The system integrates mathematical plant modeling (Black Box identification), embedded microcontroller firmware on an ATmega328P, and a custom Python desktop GUI for live serial telemetry and PID parameter tuning. An inductive proximity sensor detects passing objects, prompting a high-speed servo mechanism to sort metal and non-metal items seamlessly while the PID algorithm maintains constant conveyor speed under fluctuating load disturbances.

My Role & Responsibilities

Spearheaded system architecture design, theoretical control mathematics, embedded programming, and Python GUI telemetry development:

  • System Architecture & Electrical Wiring Design: Formulated the end-to-end hardware architecture and drafted complete wiring schematics interfacing the ATmega328P microcontroller with the L298N motor driver, rotary encoder, inductive proximity sensor, sorting servo, OLED display, and dual power rails.
  • Full-Stack Firmware & Python Telemetry GUI: Programmed the complete embedded control firmware (C/C++) and built a custom Python desktop GUI via serial FTDI—enabling real-time tuning of $K_p$, $K_i$, and $K_d$ gains, setpoint modification, and live transient response plotting.
  • Mathematical Modeling & Black Box System Identification: Derived the plant transfer function of the physical conveyor using empirical step-test Black Box modeling ($G(s) = \frac{0.37}{0.085s + 1}$), and calculated exact analytical PI controller parameters ($K_p = 0.99, \tau_i = 0.041$) to meet target settling times ($t_s \le 0.5\text{s}$) and damping ratios ($\zeta = 0.74$).
  • Hardware Implementation & Disturbance Rejection Testing: Deployed the tuned controller onto the physical plant and executed extensive closed-loop data acquisition, proving steady-state velocity stability under heavy load disturbances (612g and 1224g payloads).
  • Cost Estimation & Bill of Materials (RAB): Developed the comprehensive Bill of Materials (BOM) and budget expenditure plan (Rencana Anggaran Biaya) for all electromechanical parts, mechanical framing, acrylic paneling, and sensors.
  • Technical Documentation & Reporting: Co-authored and synthesized the comprehensive engineering report, detailing transfer function derivations, block diagrams, flowchart algorithms, and empirical test analyses.

Key Features & Control Engineering Outcomes

Analytical PID Tuning

Transfer function modeled via Black Box ($G(s) = \frac{0.37}{0.085s + 1}$) yielding rapid response without excessive overshoot.

Real-Time Python GUI

Custom desktop interface communicating via FTDI serial for on-the-fly PID gain updates and real-time response curve plotting.

Disturbance Rejection Tested

Conveyor maintained steady-state velocity under severe dynamic load perturbations of 612g and 1224g with minimal error.

Automated Sorting Logic

Inductive sensor-driven servo gating reliably segregated metallic vs. non-metallic objects without slowing conveyor throughput.
