Project Information

  • Category: Embedded Module
  • Board: Wemos D1 Mini (ESP8266)
  • Type: Freelance learning module for high school students
  • Documentation: Drive folder

Project Overview

A learning module for plant watering that reads soil moisture and the water tank level, and drives a relay pump. It was delivered in two firmware versions: a timed version that runs the pump for a user-set duration with an on-screen countdown, and an automatic version that waters whenever soil moisture falls below an adjustable threshold.

Both versions use a menu on the OLED with push-button navigation, and keep their settings in EEPROM so they survive power loss.

My Role

Designed the circuit, wired the hardware, wrote both firmware versions including the menu system and EEPROM storage, calibrated the sensors, and delivered the module to the client.

Key Features & Results

Tank Volume %

HC-SR04 level calibrated between full (3 cm) and empty (11 cm).

Calibrated Moisture %

Soil sensor mapped between dry (ADC 800) and wet (ADC 300).

Timed and Automatic Pumping

Active-LOW relay with a live mm:ss countdown, or automatic watering below the moisture threshold.

OLED Menu + EEPROM

Push-button navigation with debounce, long-press and auto-repeat; settings stored in EEPROM.
