Project Overview

A distributed IoT-based smart waste sorting and telemetry system developed and replicated for the Department of Electrical Automation Engineering, ITS. Scaling an advanced capstone concept into a multi-node deployment, the project encompasses three identical station sets deployed across three departmental laboratories (Lab A, Lab B, and Lab C). Each station pairs a local camera feed powered by a trained YOLO (You Only Look Once) deep learning model for real-time waste object detection and classification (Inorganic, Organic, and Hazardous/B3) with an ESP32-controlled physical unit. Once YOLO identifies the waste category, actuation commands trigger motorized servo lids to open automatically, while continuous ultrasonic sensors track bin fill capacity and precision strain-gauge load cells record disposal weight—streaming empirical telemetry over HTTP to a centralized MySQL database (phpMyAdmin) and real-time monitoring web dashboard.

My Role & Responsibilities

Responsible for electrical architecture engineering, firmware programming, multi-sensor calibration, database architecture, and multi-unit replication:

  • Electrical Design, Simulation & Embedded Firmware: Formulated the complete hardware schematic, simulated component interactions, and developed the C/C++ firmware on the ESP32-WROOM to coordinate 3x HC-SR04 ultrasonic sensors, 3x HX711 strain-gauge amplifiers, 3x servo lid mechanisms (triggered upon receiving real-time YOLO vision detection commands), and HTTP data transmission.
  • Multi-Sensor Precision Calibration (Load Cell & Ultrasonic): Executed rigorous calibration routines for 3x strain-gauge load cells using 24-bit HX711 ADCs with tare compensation to ensure gram-level accuracy, and calibrated lid-mounted ultrasonic sensors to reliably compute container fill volume percentages (0%–100%).
  • Relational Database Architecture (phpMyAdmin / MySQL): Architected and built the relational MySQL database schema via phpMyAdmin to log real-time multi-variable telemetry (station ID, waste category weight, bin volume percentage, and timestamp) for live web dashboard visualization.
  • Multi-Station Hardware Deployment & Wiring: Fabricated, hand-wired, and deployed 3 identical functional smart bin stations across Lab A, Lab B, and Lab C, integrating dedicated 12V 7Ah power regulation, DC-DC step-down converters, and robust industrial cable management.
  • Budgeting (RAB) & Technical Reporting: Formulated the Bill of Materials (BOM) and budget expenditure plan (RAB) for the 3-node scaling, and authored technical documentation detailing wiring schematics, calibration protocols, and communication flowcharts.

Key Features & Engineering Outcomes

3-Node Distributed Deployment

Successfully replicated and deployed 3 independent station nodes across departmental labs communicating via HTTP to a central server.

Dual Fill & Weight Telemetry

Ultrasonic fill monitoring (0%–100%) paired with precision load-cell weight tracking per waste category (Inorganic, Organic, B3).

Centralized MySQL Logging

Structured relational database hosted on phpMyAdmin capturing historical disposal trends, capacity warnings, and station health.

YOLO-Driven Servo Lid Gating

Automated motorized lid actuation commanded by real-time YOLO object detection to ensure hands-free disposal and prevent category mixing.
